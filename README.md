# Geometry Functions

Небольшой учебный проект на Python с набором функций для вычисления
**площади** и **периметра** простых геометрических фигур: круга,
квадрата, прямоугольника и треугольника.

## Возможности

- Круг: площадь и длина окружности
- Квадрат: площадь и периметр
- Прямоугольник: площадь и периметр
- Треугольник: площадь (по формуле Герона) и периметр

## Требования

- Python 3.8+
- Стандартная библиотека (используется только модуль `math`)

## Пример использования

```python
from main import circle_area, triangle_perimeter

print(circle_area(3))               # 28.274333882308138
print(triangle_perimeter(3, 4, 5))  # 12
```
